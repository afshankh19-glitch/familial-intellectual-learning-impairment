## Project overview
This repository documents a clinical and variant-prioritization assessment of familial intellectual and learning impairment associated with reduced head circumference.

## Variant-filtering workflow
The instructional filtering workflow used for the project was:

1. Start with approximately **570,550 variants**.
2. Filter `Func.refGene` to retain **exonic** variants, leaving approximately **24,214 variants**.
3. Review/filter the `CLINSIG` annotation for entries containing **Pathogenic** classifications.
4. This workflow produced **19 variants** for subsequent review.

The 19 genes observed in the instructional output were: **ALG6, F5, FMO3, CYP1B1, TTN, COG5, CFTR, RPL11, IMPAD1, GRHPR, ABCC2, HBB, MYO7A, ROBO3, AIPL1, TCAP, DYM, ABHD12, and PRODH**.

## Additional candidate assessment
A separate candidate assessment considered **TBC1D32**, including its variant annotation and the role of segregation analysis and Sanger sequencing in validation. Candidate status should not be interpreted as proof of pathogenicity without appropriate clinical, segregation, population-frequency, and validation evidence.

## Pedigree and validation
The project report includes a pedigree reconstructed from the supplied family description and discusses the use of **Sanger sequencing** and **segregation analysis** for follow-up validation.
